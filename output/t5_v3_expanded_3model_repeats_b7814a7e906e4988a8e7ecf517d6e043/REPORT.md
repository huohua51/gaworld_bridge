# T5-v3 扩展密封三模型双重复报告

## 正式结论

本轮严格遵循联合预注册并完成 288/288 个逻辑调用，但注册 Gate **未通过**。GLM-5.2 与
gpt-5.4 各自 24/24 格 FullPass；qwen3.7-plus 为 14/24 格 FullPass。Qwen 的第 60–96
个逻辑调用全部被 qweapi 以 HTTP 403“用户额度不足”拒绝。根据预注册的固定分母、禁止补替和
无效响应留在分母规则，这 37 次运营性失败不能删除或重跑，因此
`all_registered_outcomes_pass=false`。

## 预注册与设计

- 预注册 ID：`T5-V3-EXPANDED-3MODEL-REPEAT-v1`
- 预注册 SHA-256：`9b76496a3e39ff529ca5e0341d35b9a7a9d2015161914d0d2e7fed085d2aca01`
- 预注册推送提交：`2eaa6426feaca95bd48d877b114522ae4138e77b`
- 冻结基线提交：`27fe41523ed651cb73fd6e7311f70007a3ecc9e6`
- 矩阵：4 个新任务 × 3 种政策状态 × 3 个模型 × seed 0/1 × 4 个居民
- 总计：72 格、288 次逻辑调用；每模型 24 格、96 次调用
- 固定顺序：模型 → seed → 任务 →政策状态 → 居民
- `ranking_eligible=false`

四个任务的任务 ID、政策 ID、渠道、角色、群体、动作和状态字段，与全部既有 T5 开发任务及
第一批密封留出集合不相交。seed 0/1 是 byte-identical 输入的独立重复调用标签；适配器没有
单独的 provider random seed 参数。

## 按模型结果

| 模型 | 有效响应 | FullPass | seed 0 | seed 1 | absence / binding / nonbinding 变化率 |
| --- | ---: | ---: | ---: | ---: | --- |
| GLM-5.2 | 96/96 | 24/24 | 12/12 | 12/12 | `0 / 0.5 / 0` |
| gpt-5.4 | 96/96 | 24/24 | 12/12 | 12/12 | `0 / 0.5 / 0` |
| qwen3.7-plus | 59/96 | 14/24 | 12/12 | 2/12 | `0 / 0.3125 / 0` |

GLM-5.2 与 gpt-5.4 的 JSON 契约、scope 语义、directive 服从和政策响应均为 1.0。
Qwen 的正式同类指标均为 0.5833，因为 10 个格子包含配额拒绝；这是固定分母结果，不能用
available-case 重算替代。作为诊断，三个模型合计 251 个实际有效响应中，251/251 的结构化
scope 字段与冻结 resident directive 精确一致；Qwen 已返回的 59 个有效响应也是 59/59。
这不能证明缺失的 37 次本来也会正确。

## 跨模型与重复

- 跨模型 Prompt 身份率：24/24 = 1.0。
- 跨模型注册结果精确一致：14/24 = 0.5833。
- 模型内重复 Prompt 身份率：36/36 = 1.0。
- 模型内重复注册结果精确一致：26/36 = 0.7222。
- GLM-5.2 与 gpt-5.4 各自 12/12 个任务×状态重复精确一致。
- Qwen 为 2/12；其余 10 个比较受 seed 1 的配额拒绝影响。

这些精确一致率把无效响应留在注册分母中，因此同时反映协议输出与运行可获得性。不能把
0.5833 或 0.7222 解释为纯模型语义一致率。

## 独立审计

- 请求 288、响应记录 288、有效 251、无效 37、阻断 0。
- 37/37 个无效响应均为 qwen3.7-plus 的 HTTP 403 额度不足，从该模型逻辑调用 60 开始。
- 有效响应对冻结 scope/directive 的精确语义符合率：251/251。
- Prompt 中旧 `required_action` 键命中：0。
- 注册设计遵循：`true`；Prompt 跨模型和跨重复身份率均为 1.0。
- 输出中用户 API key 精确命中和常见 token 模式命中：0。

## 结论边界与恢复规则

本轮强化了 GLM-5.2 与 gpt-5.4 在四个新增表面、两个重复上的证据，也为 Qwen 留下了完整
seed 0 与部分 seed 1 证据；但三模型联合主结果是失败，不能事后改成通过。若补充 qweapi 额度，
必须新建并推送独立的 Qwen recovery 预注册后再运行，当前 288 次调用和失败 Gate 永久保留。
即使恢复完成，证据仍不支持真人效度、现实政策效果、广泛任务/模型泛化或排行榜结论。
