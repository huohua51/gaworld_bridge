# T4-v2 gpt-5.4 第二模型复测报告

## 结论

第二模型复测已按预注册启动，但在不计分校准Gate被Provider阻断，正式60调用矩阵
没有启动。

| 校准项 | 结果 |
|---|---:|
| source严格JSON | 失败 |
| target严格JSON | 失败 |
| HTTP状态 | 两次均403 Forbidden |
| 逻辑调用 / 物理尝试 | 2 / 2 |
| 重试 | 0 |
| 正式T4格 | 0/18（未启动） |

两次响应正文均为空，错误发生在Paratera网关，模型名固定为`gpt-5.4`。按照
`T4-REGISTERED-TRANSPORT-GPT54-v1`，校准必须2/2严格有效才可启动正式矩阵，
因此停止是协议遵循，不是漏跑。没有改用GLM-5.2冒充第二模型，也没有把校准失败
计入T4功能分数。

当前T4结论仍是：GLM-5.2在固定v2协议上seed0/1/2稳定；gpt-5.4跨模型复现保持
`provider_blocked`，等待该模型在网关上具备可用权限或额度后，必须新建预注册再跑。
