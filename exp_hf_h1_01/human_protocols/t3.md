# 真人协议：T3 审核协作（Full Multi）

与 Agent 刺激同一任务表面、同一动作空间。不用 Single，也不用丢弃审核消息。

## 角色

| 角色 | 做什么 | 不能做什么 |
|---|---|---|
| 起草人 | 按公开说明写一版代码草稿 | 看不到本轮私有核验标准 |
| 审核员 | 对照本轮可见标准决定 keep 或 update | 不改文件 |
| 执行人 | 读取审核意见后确认或按 required_changes 改草稿 | 不能发明审核里没有的修改 |

## 变体

- A：公开标准与私有标准一致，通常 keep。
- B：私有标准已更新，审核员看得到新值，起草人起草时看不到。

## 输出

每人只交一个结构化对象（代码或 JSON）。保存为与 Agent 相同的三回合轨迹。
