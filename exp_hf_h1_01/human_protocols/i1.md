# 真人协议：I1 核实信息传播（Full）

观察员、核验员、调度员三人顺序工作。不用 Drop，也不允许调度员直接读私有可信表。

## 角色

| 角色 | 做什么 | 不能做什么 |
|---|---|---|
| 观察员 | 把两个来源的报告原样发出 | 不判断谁可信，不提交最终动作 |
| 核验员 | 按私有可信表选出可信来源状态 | 不提交最终动作 |
| 调度员 | 只根据已核实消息按规则提交动作 | 不读可信表，不采用未核实传闻 |

## 变体

- A / B 只改变可信来源报告的状态和应对动作。规则本身不变。

## 输出

三回合：报告数组 → verified 对象 → action 对象。
