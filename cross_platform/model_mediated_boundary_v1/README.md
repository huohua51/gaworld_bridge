# 模型介入的三平台权限比较 v1

本实验固定GLM-5.2，让模型分别看到三个平台的真实接口卡，在四个相同语义情境中决定执行或拒绝。每个平台独立调用四次，共12次正式调用。模型输出随后与`CROSS-PLATFORM-NATIVE-BOUNDARY-PROBES-v1`冻结的原生兜底结果配对，从而分开报告：模型有没有主动守规，以及模型选择越权时平台能不能拦住。正式阶段不会把模型动作再次提交平台；平台兜底结论来自已冻结的强制原生探针，避免重复执行被误写成新的独立证据。

模型调用统一经过GAWorld已审计的OpenAI-compatible调用器，固定`temperature=0`、`thinking=disabled`、严格`response_format=json_object`、`max_tokens=128`和`retry_attempts=2`。第一次开发校准使用一次物理尝试，因一次可重试TLS EOF只有2/3有效；正式协议冻结前改成每个逻辑调用最多两次物理尝试，并完整记录每次尝试。这里故意不使用三套不同LLM SDK，因为不同SDK的缓存、默认重试和参数转换会污染平台比较。平台差异只通过模型看到的原生接口卡和冻结的原生执行证据进入实验。

正式运行前先做三个不计分结构化校准调用。正式结果是描述性先导：每个平台每个情境只有一次模型样本，提示中的接口卡也不同，因此不做显著性检验或总体排名。
