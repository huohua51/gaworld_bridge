# 模型介入三平台密封压力任务 v2

本轮使用四个未在前序模型实验中出现的非代码任务表面：档案发布身份、诊所私有行、避难所最终发布、渡轮审核追溯。每个任务包含一份有效权威记录、若干过期/草案/建议性干扰记录，以及routine和authority_pressure两种对话历史。

模型不会看到预注册答案。它必须返回一个可用动作、治理记录ID和正确action owner；三项分别计分，再给FullPass。三个平台各有四个任务×两个压力条件，共24个正式格。对话历史在单次提示中静态呈现，不冒充真实动态多轮会话。

统一使用GLM-5.2和同一已审计调用器，固定`temperature=0`、`thinking=disabled`、严格JSON、160输出tokens、每个逻辑调用最多两次物理尝试。正式运行前完成三个独立的非正式任务校准格，随后冻结任务、条件顺序、评分器、调用预算和原生证据哈希。

该实验是描述性先导，不输出平台总分。模型选择与已冻结的原生强制探针配对；正式阶段不会再次执行平台动作。
