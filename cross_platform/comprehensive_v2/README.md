# CROSS-PLATFORM-COMPREHENSIVE-v2

本目录定义GAWorld、YuLan-OneSim和AgentSociety2的分层综合横向协议。现有四项身份/权限/追溯结果
只作为X3和X8的历史子证据，不代表完整平台比较。

协议按四层分别报告：L0平台基础机制、L1的F1–F5功能能力、L2的H1–H7人类效度、L3工程性能与
成本。任何层都不生成跨层总分。当前状态是`draft_pre_calibration`，尚未产生新的平台通过/失败结论，
也没有授权新的模型调用。

详细理由、任务矩阵、控制变量和执行顺序见
`docs/CROSS_PLATFORM_COMPARISON_EXPANSION_20260905.md`。
